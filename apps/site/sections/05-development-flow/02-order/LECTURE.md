# 02 作る順番

![作る順番](./images/00-thumbnail.svg)

前の節で「仕組みを先、装飾を後」という方針を見ました。この節では、その方針を実際の作る順番に
落とし込みます。この教材そのものが、その順番で並んでいます。

## 小さな一歩に分ける

大きな機能をいきなり作ろうとせず、**1回に1つだけ**足すのがコツです。この教材の各節は、
前の節のコードに「差分（ちがい）」を1つ足すだけになっています。1歩ごとに動かして確かめられるので、
どこで失敗したかがすぐ分かります。

## 土台から応用へ

作る順番は、下から積み上げるイメージです。

```text
1. 表示        … 画面に物を出す（鳥を表示）
2. 物理        … 重力・地面・当たり判定
3. 操作        … クリック → パチンコで発射 → 狙いの線
4. 画面の流れ  … スタート／残弾／ゲームオーバー、シーン分割
5. ルール      … 標的・クリア・スコア・リザルト
6. 装飾        … 画像・効果音・BGM・設定
```

下の段ができていないと上の段は作れません。たとえば「当たったブタを消す」は、先に物理の
当たり判定がないと作れません。だから土台（表示・物理）から順に積み上げます。

## 仮のもので進め、後で本物にする

途中では「仮のもの」で進めて構いません。この教材でも、鳥やブタは最初ただの丸で、箱はただの
四角でした。仕組みが固まってから、最後に本物の画像に差し替えました。仮のもので先に進め、
後から本物にする——これも作り切るための大事なコツです。

## リファクタも忘れずに

コードが増えて読みにくくなったら、**動きを変えずに整理する**のも大切な一歩です。この教材では
`11 シーンごとにファイルを分ける` で、増えたコードをファイルに分けて整理しました。整理して
おくと、その後の機能追加がぐっと楽になります。

## まとめ

- 1回に1つだけ足す（小さな一歩）。
- 土台から応用へ、順に積み上げる。
- 仮のもので進め、後で本物にする。
- 増えたら整理する（リファクタ）。

この進め方は、パチンコゲームに限らず、いろいろな物作りに使えます。
