# 03 ブラウザで動かす

![ブラウザで動かす](./images/00-thumbnail.svg)

作ったゲームはブラウザで動きます。この節では、ブラウザで開く方法と、困ったときに役立つ
**開発者ツール（DevTools）** の使い方を軽く見ておきます。

## ブラウザで開く

`index.html` をブラウザで開けばゲームが動きます。開き方は **Live Server 経由** にしてください。

前の節で入れた Live Server で `index.html` を右クリック →「Open with Live Server」を選びます。
右下のバーの **Go Live** を押しても同じです。画像も音も問題なく読み込めます。Cursor などの
VS Code 系エディタでも、メニューの位置も名前も同じです。

`index.html` をダブルクリックして直接開く方法（`file://`）でも一見動きますが、あとの章で
画像や音の読み込みに失敗します。とくに音は鳴りません。最初から Live Server で開く癖をつけておきましょう。

## 開発者ツール（DevTools）を開く

開発者ツールは、ブラウザに最初から入っている「ページの中を覗く」道具です。開き方は OS ごとに違います。
ここでは Chrome / Edge を想定して書きます。

### macOS で開く

- **ショートカット** … `Command + Option + I`
  - Console タブを直接開きたいときは `Command + Option + J`
- **右クリック** … ページの上で右クリック（トラックパッドなら二本指クリック）→「検証」

`F12` は macOS では音量や明るさの操作に割り当てられていることが多く、そのままでは効きません。
押すなら `fn + F12` です。ショートカットは `Command + Option + I` を覚えておくのが確実です。

### Windows で開く

- **ショートカット** … `F12`、または `Ctrl + Shift + I`
  - Console タブを直接開きたいときは `Ctrl + Shift + J`
- **右クリック** … ページの上で右クリック →「検証」

### コンソールを見る

開発者ツールの中の **Console（コンソール）** タブには、コードからのメッセージやエラーが表示されます。
うまく動かないときは、まずここを見ると原因のヒントが見つかります。

たとえば、コードに次のように書くと、コンソールに文字を出せます。下の実行結果は、この
ページを開いているあなたのブラウザのコンソールにも表示されています（上の方法で開いて確認してみてください）。

:::script

```js
console.log('こんにちは！ ここがコンソールです。');
```

:::

- `console.log('...')` … かっこの中身をコンソールに表示します。値の確認やデバッグに使います。

## 準備完了

これで、コードを書く道具（エディタ）と、動きを確かめる道具（ブラウザと DevTools）がそろいました。
