# 03 ブラウザで動かす

![ブラウザで動かす](./images/00-thumbnail.svg)

作ったゲームはブラウザで動きます。この節では、ブラウザで開く方法と、困ったときに役立つ
**開発者ツール（DevTools）** の使い方を軽く見ておきます。

## ブラウザで開く

`index.html` をブラウザで開けばゲームが動きます。開き方は2通りあります。

- **ダブルクリック** … `index.html` を直接開きます。手軽ですが、画像や音を使う章では読み込みに失敗することがあります。
- **Live Server 経由**（おすすめ） … 前の節で入れた Live Server で開きます。画像や音も問題なく読み込めます。

## 開発者ツール（DevTools）を開く

ブラウザで `F12` キー（または右クリック →「検証」）を押すと、開発者ツールが開きます。
その中の **Console（コンソール）** タブには、コードからのメッセージやエラーが表示されます。
うまく動かないときは、まずここを見ると原因のヒントが見つかります。

たとえば、コードに次のように書くと、コンソールに文字を出せます。下の実行結果は、この
ページを開いているあなたのブラウザのコンソールにも表示されています（`F12` で確認してみてください）。

:::script
```js
console.log('こんにちは！ ここがコンソールです。');
```
:::

- `console.log('...')` … かっこの中身をコンソールに表示します。値の確認やデバッグに使います。

## 準備完了

これで、コードを書く道具（エディタ）と、動きを確かめる道具（ブラウザと DevTools）がそろいました。
次の章から、実際に `game/` を作り始めます。
