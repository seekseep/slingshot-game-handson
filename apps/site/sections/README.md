# はじめに

Phaser 3 + Matter.js で「パチンコ物理ゲーム（アングリーバード風）」を、少しずつ組み立てていくハンズオンです。
鳥をパチンコで飛ばし、積み上がった箱を崩して標的を倒すゲームを作ります。

## この教材の構成

**章（section）** と **節（lecture）** の 2 階層で進めます。章はテーマのまとまり、節は「1 つの動く状態」です。

| 章 | 種別 | 内容 |
| --- | --- | --- |
| [01. はじめに](./01-introduction/) | 準備 | 完成版を触る・エディタ・ブラウザ |
| [02. 基本を作る](./02-basic/) | 実装 | 鳥の表示からパチンコ発射・シーン分割まで（白黒） |
| [03. ゲームの仕組み](./03-game-engine/) | 解説 | Canvas・物理エンジン・画面（UI）の考え方 |
| [04. ゲームロジック](./04-game-logic/) | 実装 | 標的・残弾・クリア判定・スコアなど「ゲームらしさ」を作る |
| [05. 開発の進め方](./05-development-flow/) | 解説 | 装飾のない状態から作り込む進め方 |
| [06. 装飾を足す](./06-additional-features/) | 実装 | 画像・効果音・BGM・設定を足して仕上げる |

## 進め方

- **基本はコードを自分で組み立てます。** 各節は前の節のコードに差分を足していく形で進みます。
- **追いつけなくなっても大丈夫。** 各節の末尾に「完成例」パネル（簡易エディタ UI）があり、
  左でファイルを選び、右でコードを確認できます。ZIP でダウンロードして続きから始められます。
- **構成が変わるときはファイル構成を示します。** どのファイルをどう増やしたかが分かります。

## 各節の完成コードの置き場所

各節の完成コードは、その節のフォルダの `example/` に入っています（`sections/<章>/<節>/example/`）。
ダウンロードした ZIP を展開したものと同じ中身です。

## 動かし方（共通）

`example/index.html` を開くだけで動きますが、画像や音を使う節では `file://` だと読み込みに
失敗します。エディタ章で入れる **Live Server**、または簡易サーバーで開いてください。

```sh
python3 -m http.server 8000
# 例: http://localhost:8000/sections/02-basic/01-bird/example/
```

Phaser 本体は CDN（cdnjs）から読み込むため、インストールは不要です。
