# パチンコ物理ゲーム ハンズオン

Phaser 3 + Matter.js で「パチンコ物理ゲーム（アングリーバード風：鳥をパチンコで飛ばして構造物を崩し、標的を倒す）」を
少しずつ作っていく教材です。手を動かしてコードを組み立てながら進めます。

まずは白黒の図形だけで物理と操作を作り、次にゲームのルール（標的・残弾・スコア）を足し、
最後に画像や音で装飾していきます。

Phaser 本体は CDN（cdnjs）から読み込みます。
